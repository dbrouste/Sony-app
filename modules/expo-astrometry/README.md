# expo-astrometry

Local Expo module providing offline Astrometry.net plate solving on Android.
Index files are downloaded separately into the application's external files directory.

The native solver integration is derived from
[`DIPE014/Astro-Mobile-App`](https://github.com/DIPE014/Astro-Mobile-App) and the
Astrometry.net sources. See `THIRD_PARTY_NOTICES.md` at the application root.
